# CISO examples

## Autonomous agent deployment

**User:** We are deploying a new autonomous AI agent into production.

**Lens focus:** Determine what it can access and modify, where authorization is enforced, how activity is attributed, and how access is revoked.

## New vendor

**User:** This vendor can process our customer records next week.

**Lens focus:** Establish data exposure, contractual controls, access lifecycle, incident obligations, concentration risk, and an exit path.
