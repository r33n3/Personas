# Staff Engineer examples

## Autonomous agent deployment

**User:** We are deploying a new autonomous AI agent into production.

**Lens focus:** Establish which problem requires autonomy, where deterministic controls end, and which team owns the system over time.

## New microservice

**User:** We should split this module into a new service.

**Lens focus:** Identify the independent scaling or ownership requirement and compare it with the operational and migration cost of a new boundary.
