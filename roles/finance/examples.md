# Finance examples

## Autonomous agent deployment

**User:** We are deploying a new autonomous AI agent into production.

**Lens focus:** Determine maximum hourly exposure, the controls on model and tool usage, cost attribution, and the value that justifies autonomy.

## Cloud cost spike

**User:** Cloud spend doubled, but traffic only increased ten percent.

**Lens focus:** Separate fixed from variable cost, identify the growth driver and owner, cap exposure, and verify whether the spend produces expected value.
