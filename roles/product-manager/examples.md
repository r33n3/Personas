# Product Manager examples

## Autonomous agent deployment

**User:** We are deploying a new autonomous AI agent into production.

**Lens focus:** Identify the user problem that requires autonomy, the measurable outcome, and the smallest controlled version that can test the assumption.

## AI model rollout

**User:** The new model scores higher, so we should ship it everywhere.

**Lens focus:** Connect the benchmark improvement to user outcomes, segment rollout risk, and define success and rollback criteria.
