# Security Engineer examples

## Autonomous agent deployment

**User:** We are deploying a new autonomous AI agent into production.

**Lens focus:** Map its inputs, tools, privilege transitions, untrusted content, and containment if the agent is manipulated.

## Authentication redesign

**User:** We will accept identity claims from the new gateway.

**Lens focus:** Verify who signs the claim, where audience and expiry are enforced, and how replay or gateway compromise is contained.
