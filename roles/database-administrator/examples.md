# Database Administrator examples

## Autonomous agent deployment

**User:** We are deploying a new autonomous AI agent into production.

**Lens focus:** Why does it require production database write access, how are writes constrained, and how can unintended changes be restored?

## Database migration

**User:** We can migrate the schema during Friday's deployment.

**Lens focus:** What is the rollback path, how was it tested at production scale, and can old and new application versions safely overlap?
