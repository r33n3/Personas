# Role Lens Catalog

The initial catalog intentionally contains eight strongly differentiated perspectives. Absence of a lens is the neutral condition; there is no empty “generalist” lens.

## Technology

- **Database Administrator** — durability, recoverability, consistency, query behavior, and safe schema change.
- **Site Reliability Engineer** — availability, failure modes, observability, sustainable operations, and recovery.
- **Staff Engineer** — problem framing, system coherence, maintainability, technical leverage, and cross-team cost.
- **Security Engineer** — attack paths, trust boundaries, secure defaults, secrets, and abuse resistance.

## Leadership

- **CISO** — organizational risk, controlled access, accountability, revocation, and policy enforcement.

## Product

- **Product Manager** — user value, evidence, scope, prioritization, adoption, and measurable outcomes.

## Business and governance

- **Finance** — total cost, forecastability, contractual exposure, return, and downside limits.
- **Auditor** — evidence, traceability, control design, control operation, exceptions, and accountability.

## Deferred catalog

Cloud Architect, Frontend Engineer, Data Scientist, Legal, Procurement, Risk Manager, and other lenses remain design candidates. Enterprise Architect is deliberately deferred because the persona catalog already contains a comedic Enterprise Architect character; the project should establish an unambiguous display convention before using the same label for both concepts.

New lenses should introduce a meaningfully different attention pattern. Repeated response actions belong in behavioral profiles, while changes that merely alter delivery belong in personas or presentation.
